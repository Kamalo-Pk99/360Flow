# 360Flow

A 360° video and photo viewer and editor that runs entirely in your browser. Nothing is uploaded.

## Features
- Play 360 videos and photos, drag to look around, scroll or pinch to zoom
- Insta360 `.insv` and `.insp` files (dual fisheye is stitched live)
- Playlist from files or a folder, with thumbnails
- View modes: Re-framed 16:9, Mobile 9:16, Full 360, Tiny Planet, FPV Wide
- Camera path keyframes (camera and speed glide between keyframes)
- Color grading and filters, including a UV / haze filter
- Slow motion and fast motion (0.1x to 4x)
- Background music with volume mixing
- Record the edited view (with sound) as a downloadable video

## Run it
Open `index.html` in Chrome, Edge or Safari. An internet connection is needed to load three.js from a CDN.

For all features (such as remembering your last playlist) serve it over http, for example with GitHub Pages:
Settings > Pages > Deploy from a branch > `main` / root.
